# Telegram dan Viewer

## Telegram

Notifikasi berisi ticket key, summary aman, status, assignee, priority, jenis tiket, dan hasil aman. Intake-only memakai judul khusus yang menyatakan AI/SIEM disabled. Operational alerts dideduplikasi berdasarkan fingerprint.

## Status Viewer

Read-only local dashboard untuk Workers, Feature & AI Health, Service Health, Ticket Processing, Timeline, History, dan Safety. Tidak menampilkan raw SIEM, prompt, token, atau secret.

## Documentation Viewer

Bahasa Indonesia default, English kedua. Menyediakan sidebar, breadcrumb, full-text search index, table of contents, copy button, responsive layout, print mode, version badge, dan last reviewed metadata.
