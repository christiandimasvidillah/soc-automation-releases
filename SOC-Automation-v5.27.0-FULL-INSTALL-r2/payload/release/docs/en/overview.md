# System Overview

SOC Automation performs Jira intake and triage, retrieves SIEM evidence, protects sensitive data, runs controlled AI analysis, updates Jira, sends Telegram notifications, and executes policy-bounded Auto-FP. Core components are Jira, Elastic/Kibana, deterministic Python sanitization, Local AI path discovery, Gemini analysis after privacy approval, SQLite reliability state, SocMaster blue/green supervision, TUI control, and read-only viewers.
