# Complete TUI Reference

Dashboard shows runtime, services, features and AI. Runtime Control includes restart, stop, cutover, deployment status, Start All, and Graceful Stop All. Update Manager performs inspect, checksum, dry-run, transactional runtime deploy, Manager/TUI update, and status. Audit/Log viewers use local path and safety restrictions. Diagnostics cover health, preflight, readiness, privacy, AI, observability, backup, qualification, and VT/SMB. Viewer Services manages ports 8765/8766. Release and Rollback restores validated releases atomically. Maintenance includes cleanup, compile, retention, backup, reconciliation, reprocess, allowlist, evidence tools, Auto-FP, and Manual False-Incident. Feature Control Center manages profiles, individual features, dependencies, revisions, and effective state.
