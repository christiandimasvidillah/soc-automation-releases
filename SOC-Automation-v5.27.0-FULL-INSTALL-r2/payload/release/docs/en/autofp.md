# Auto-FP and Manual Reconciliation

SMB evidence is constrained to rule, host, process, source, destination port, and time window. No-observed-success requires no established/authentication/transfer/success evidence, clean VT fan-out, and no high-risk blockers. Controlled Auto-FP uses kill switches and rate limits. Background modes are DISABLED, SHADOW, APPROVAL, LIMITED, and GLOBAL with binding, TTL, UUID/hash, idempotency, and circuit breaker. Manual reconciliation validates scope, owner, analysis, raw audit, identity, and status before action.
