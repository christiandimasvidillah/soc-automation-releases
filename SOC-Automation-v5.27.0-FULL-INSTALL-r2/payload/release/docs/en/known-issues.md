# Known Issues and Limitations

The current TUI source may differ from the manager launcher; use displayed version and package metadata. Code rollback does not reverse completed external Jira/SIEM actions. Credentials are shown only as CONFIGURED/MISSING. Feature changes apply to new work while active tickets retain their snapshot. Full-text search indexes the active documentation build.
