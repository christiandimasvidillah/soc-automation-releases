# Testing and Acceptance

Minimum gates: Python compile/import, JavaScript syntax, ZIP/SHA-256, release dry-run, TUI/documentation parity, Indonesian/English parity, internal route/link check, secret scan, privacy regression, Jira/SIEM no-action, intake-only, feature dependencies, viewer read-only/loopback, and malicious-backup-member rejection. A release fails when implementation changes but documentation, notes, migration, rollback, or history are missing.
