# Feature and AI Control Center

Individual features control Jira polling, SIEM retrieval, privacy sanitization, Local AI, Gemini, VirusTotal, sharing allowlist, Telegram, Status Viewer, and Documentation Viewer. Profiles: FULL_AUTOMATION, JIRA_INTAKE_ONLY, PRIVACY_LOCAL_AI_ONLY, AI_ANALYSIS_NO_AUTO_ACTION, MAINTENANCE_SAFE_MODE, and CUSTOM. Local AI shows provider/model/endpoint/reachability/mode. Gemini shows preferred and allowed models, mode, credential status, and availability without exposing keys.
